Café Ordering & Billing System

1. Introduction

    This ordering and billing system for the cafe is simple computerized program developed in Java that assists the stuff of the café to make order selections, create orders, compute bills, and issue receipts.


2. Objectives

    i) For simplifying the process of ordering at the cafe.

    ii) For making calculations of order totals.

    iii) For making it easy to use a graphical user interface.

    iv) For printing out receipts for the customer' orders.


3. Main Features

    i) Show seven menu items in the cafe with their prices.

    ii) Choose the menu items and put the quality.

    iii) Add the items into present order.

    iv) Total bill is calculated automatically.

    v) Remove a selected item from an order.
    
    vi) Clear the present order.

    vii) Print out the receipt.

    viii) Show warning messages with the order is empty or the item is not selected.


4. Technologies Used.

    i) Programming Language: Java

    ii) GUI: Java Swing

    iii) IDE: IntelliJ IDEA

    iv) Version Control and Repository Hosting: Git and GitHub


5. User Role

    Café Staff: Using the application, the staff selects menu items, manages orders, calculates totals, and produces receipts.

7. Limitations

   i) There is no database used in the program.

   ii) There is no permanent saving of orders.

   iii) There is no online payment system or customer account includeed in the program.


8. Future Enhancements

   i) Save orders in a database.

   ii) Include sales reports.

   iii) Include discounts.

   iv) Include order history.


9. Conclusion

    The project illustrate use of Java programming, object oriented programming, GUI designing, events, and billing calculation.
